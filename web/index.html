How it works

1

Install the package

Add Sphegatti to your React Native project and wire up the native Android module once.

2

Get your API key

Sign up above and copy your key into ota.config.js — that's it for setup.

3

Publish an update

Run npx ota publish. Metro bundles your JS, uploads it, and the release goes live in seconds.

4

Users get it automatically

The SDK checks for updates on every app launch and applies them silently in the background.
