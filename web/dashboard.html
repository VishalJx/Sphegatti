Quick setup

1. Install & wire native module
npm install sphegatti
npx ota init
npx react-native run-android   # one-time native build
2. ota.config.js (created by npx ota init)
module.exports = {
  appId: 'your-app',
  runtimeVersion: '1',
  publish: {
    serverUrl: 'https://sphegatti.onrender.com',
    apiKey: process.env.SPHEGATTI_API_KEY || '',
  },
};

Set SPHEGATTI_API_KEY=YOUR_API_KEY in your environment — never commit the key directly.

3. Check for updates in your app
import { checkForUpdate } from 'sphegatti/client';
import { useEffect } from 'react';

// In your root component
useEffect(() => {
  checkForUpdate({ appId: 'your-app' });
}, []);

Handles fetching, downloading, and restarting automatically. No manual fetch or native calls needed.

4. Publish an update
export SPHEGATTI_API_KEY=YOUR_API_KEY
npx ota publish

Users receive the update on their next app open. No Play Store review needed.
